Проверено 2026-10-26. Вход: https://github.com/yy4zcbmxhx-hash/SQL_report, commit `0aa053d1fc9e1bcea0ac95bba234e4e781a2aab5`. Скачаны оба notebook, README и три CSV; PDF по ссылке https://disk.360.yandex.ru/i/Ubez1lrGroBh_g. Хеши локальных исходников: `originals/manifest.json`.

Найден прямой учебный источник: [Data With Baraa / SQL Data Analytics](https://github.com/DataWithBaraa/sql-data-analytics-project), каталог `01_datasets/csv-files/`. Сопоставление проведено по значениям всех строк с учётом повторений:

- `gold.fact_sales.csv`: все 60 398 строк совпадают с fact_sales.csv, включая пропуски дат.
- `gold.dim_products.csv`: все 295 строк совпадают.
- `gold.dim_customers.csv`: все 18 484 строки совпадают при исключении технического create_date. Поэтому create_date не используем как дату приобретения клиента.

Названия товаров и номера AW соответствуют семейству учебной AdventureWorks; Microsoft описывает её как sample database: https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure . Полная цепочка преобразований от конкретного релиза Microsoft к этим CSV не установлена, поэтому не утверждаем точную версию и не переносим автоматически лицензию другого релиза. Данные не представлены как транзакции реальной компании.

Валюты и документированного определения sales_amount/cost в трёх пользовательских CSV нет. Арифметика sales_amount = quantity × price проверена для всех строк, но это не доказывает учёт возвратов, налогов, скидок и фактических затрат. Везде используются «единицы датасета».

Исходные notebook содержат строку локального подключения с паролем. Они сохранены локально неизменными для аудита и исключены из публикационного комплекта; новая версия использует переменные окружения/libpq. Наличие этой строки не доказывает доступ к какой-либо боевой базе.
